# نشر النظام على Oracle Cloud (الخطة المجانية الدائمة)

تشرح هذه الصفحة كيف تنشر النظام على خادم مجاني في جدة أو الرياض. يعمل النظام وقاعدة بيانات PostgreSQL على نفس الخادم. الخطوات تأخذ تقريباً من 30 إلى 45 دقيقة.

## 1) إنشاء الحساب
1. سجّل في https://www.oracle.com/cloud/free/. تُطلب بطاقة بنكية للتحقق فقط، ولا يُخصم شيء في الخطة المجانية.
2. **اختر المنطقة الرئيسية (Home Region): Saudi Arabia West (Jeddah) أو Saudi Arabia Central (Riyadh).**
   - لا يمكن تغيير المنطقة الرئيسية لاحقاً.
   - موارد الخطة المجانية تُنشأ فيها فقط.
   - اختيار منطقة سعودية يُبقي البيانات داخل المملكة.

## 2) إنشاء الخادم
من القائمة: **Compute ← Instances ← Create instance**
- **Name:** `hr-server`
- **Image:** Canonical **Ubuntu 22.04** أو 24.04.
- **Shape:** Ampere ← **VM.Standard.A1.Flex**. اختر 2 OCPU و12GB ذاكرة، وهذا ضمن المجاني ويكفي النظام بسهولة.
  - إن ظهرت رسالة «Out of capacity» فحاول لاحقاً، أو اختر VM.Standard.E2.1.Micro، وهو مجاني أيضاً ويكفي لعدد موظفين محدود.
- **Networking:** اترك الإعدادات الافتراضية، وتأكد أن «Assign a public IPv4 address» مفعّل.
- **SSH keys:** اختر «Generate a key pair for me» ونزّل **المفتاح الخاص (Private key)** واحفظه في مكان آمن.
- اضغط **Create** وانتظر حتى تصبح الحالة **Running**، ثم انسخ **Public IP address**.

## 3) فتح المنفذين 80 و443 في شبكة Oracle
1. من صفحة الخادم افتح **Subnet** ثم **Default Security List**.
2. اختر **Add Ingress Rules** وأضف قاعدتين:

| Source CIDR | IP Protocol | Destination Port |
|---|---|---|
| `0.0.0.0/0` | TCP | `80` |
| `0.0.0.0/0` | TCP | `443` |

جدار الحماية داخل الخادم نفسه يفتحه سكربت التثبيت تلقائياً.

## 4) (موصى به) نطاق لتفعيل HTTPS
بدون نطاق يعمل النظام على `http://IP`، لكن **كلمات المرور تُرسل حينها دون تشفير**. للحصول على HTTPS ستحتاج اسم نطاق:
- **الأفضل:** نطاق فرعي من الجامعة، مثل `rest.nursing.ksu.edu.sa`، تطلبه من عمادة التقنية وتوجّهه إلى IP الخادم بسجل A.
- **مؤقتاً ومجاناً:** نطاق من https://www.duckdns.org، مثل `ksu-hr.duckdns.org`، توجّهه إلى IP الخادم.

## 5) التثبيت بأمر واحد
### الاتصال بالخادم
من الطرفية على جهازك (في Windows استخدم PowerShell):

```bash
chmod 600 ~/Downloads/ssh-key-*.key
```

```bash
ssh -i ~/Downloads/ssh-key-*.key ubuntu@<Public-IP>
```

### تشغيل التثبيت
داخل الخادم، **مع نطاق** (موصى به):

```bash
curl -fsSL https://raw.githubusercontent.com/Abdullh10/HR/main/deploy/install.sh | sudo DOMAIN=ksu-hr.duckdns.org EMAIL=you@example.com bash
```

أو **بدون نطاق**:

```bash
curl -fsSL https://raw.githubusercontent.com/Abdullh10/HR/main/deploy/install.sh | sudo bash
```

### ما يفعله السكربت
- يثبّت PostgreSQL، ويُنشئ قاعدة البيانات بكلمة مرور عشوائية قوية.
- يثبّت النظام في `/opt/hr`، ويشغّله كخدمة تعود للعمل تلقائياً بعد إعادة تشغيل الخادم.
- يضبط Nginx ويفتح المنفذين، ويُصدر شهادة HTTPS مجانية إن أعطيته نطاقاً.
- يجدول نسخة احتياطية يومية في الساعة 3 فجراً، ويحتفظ بآخر 14 نسخة.

في النهاية **يطبع رابط النظام وكلمة مرور الأدمن الأولى**. سيُطلب منك تغييرها عند أول دخول.

## 6) بعد التثبيت
1. ادخل بحساب `admin` وغيّر كلمة المرور.
2. **السنوات وقواعد الحساب:** راجع إعدادات سنة 2027، أي طريقة الاحتساب والرصيد الأساسي وساعات اليوم.
3. **استيراد الموظفين:** نزّل النموذج، واملأه بالأسماء والأرقام والمناصب وأرقام المديرين المباشرين، ثم ارفعه. تُنشأ الحسابات تلقائياً.
4. **(اختياري) ترحيل ملفات الإكسل القديمة:**
   1. انسخ الملفين إلى الخادم. نفّذ هذا الأمر من جهازك:

      ```bash
      scp -i key.key *.xlsx ubuntu@<IP>:/tmp/
      ```

   2. داخل الخادم، شغّل الترحيل تجربةً أولاً دون حفظ:

      ```bash
      cd /opt/hr && sudo -u hr bash -c 'set -a; . /etc/hr/hr.env; .venv/bin/python -m scripts.import_excel --balances "/tmp/إدارة.xlsx" --hours "/tmp/الساعات.xlsx"'
      ```

   3. راجع التقرير `/var/lib/hr/import_report.xlsx`، ثم أعد نفس الأمر مع إضافة `--commit` في آخره.

## الصيانة

| المهمة | الأمر |
|---|---|
| التحديث إلى آخر نسخة من GitHub (يأخذ نسخة احتياطية قبل التحديث) | `sudo hr-update` |
| نسخة احتياطية الآن | `sudo hr-backup` |
| مكان النسخ الاحتياطية | `/var/backups/hr/` (يُفضَّل تنزيلها دورياً إلى جهاز آخر بـ `scp`) |
| حالة الخدمة | `systemctl status hr` |
| السجلات | `journalctl -u hr -f` |
| الإعدادات (رابط قاعدة البيانات والمفاتيح) | `/etc/hr/hr.env` (لا تشاركه مع أحد) |

**استعادة نسخة احتياطية:**

```bash
gunzip -c /var/backups/hr/db-XXXX.sql.gz | sudo -u postgres psql hr
```

```bash
sudo systemctl restart hr
```

## ملاحظات
- **خمول الخادم:** قد تستعيد Oracle خوادم الخطة المجانية التي تبقى خاملة تماماً لفترة طويلة. الاستخدام اليومي للنظام يكفي لتجنب ذلك. ويمكنك ترقية الحساب إلى Pay As You Go مع البقاء ضمن حدود المجاني، فلا يُخصم شيء.
- **الحدود والأسعار:** حدود الخطة المجانية قد تتغير، فتحقق منها في موقع Oracle.
